## Decisioni di questo piano

Scelte che il progetto e il piano principale lasciano a C2, o che il codice impone, con il costo se sbagliate. Il Task 10 le riporta nella revisione 37 della spec.

1. **Cosa copre `security`** (progetto 11, catalogo 2). Le cartelle `auth/`, `security/` e `rls/` a qualunque profondità (fuori da `supabase/` alla radice), i file `middleware.*` e i `proxy.ts`/`proxy.js`, e i file che importano una libreria di hashing delle password o di firma e verifica dei token. Non copre: i file con «session» nel nome (scelta dell'utente), le cartelle `middleware/` e `middlewares/` (12 file in 10 progetti; non sono nel catalogo), le cartelle con la maiuscola (`Auth/`, `Security/`: il confronto distingue le maiuscole), le route group di Next.js `(auth)`, `proxy.page.ts` (Next.js con `pageExtensions`), `_middleware.ts` delle Pages Functions di Cloudflare, i file `auth.ts` di configurazione del login fuori da una cartella `auth/` (le librerie di login non sono marcatori, scelta dell'utente), le policy RLS sotto `supabase/` (restano a `database`). Costo: un file di login fuori da quelle forme e senza i marcatori resta al profilo della cartella o al generico; al contrario, le forme a cartella accendono anche file che non sono codice di login: il codice di terzi copiato nel repo (`vendor/…/auth/`, `third_party/…/security/`; 439 dei 462 file `auth/` sul disco sono in una copia di terzi), le immagini (`public/auth/`), i testi tradotti (`i18n/auth/`), e `**/middleware.*` anche un manifesto `middleware.yaml`: quei lavori salgono a L2. Rimedio gratuito: togliere quel percorso dal blocco proposto prima di copiarlo in `tollgate.toml`. La pagina porta ogni voce in «Da decidere tu».
2. **Pattern del frammento**, in quest'ordine: `["**/auth/**", "**/middleware.*", "**/proxy.ts", "**/proxy.js", "**/security/**", "**/rls/**"]`. `**/*session*` esce (scelta dell'utente del 22/11). `**/proxy.ts` e `**/proxy.js` entrano (mia scelta, compatibile e a basso costo: dalla 16 il middleware di Next.js si chiama `proxy`; 4 file sul disco). Il verificatore (Task 5) controlla ogni pattern su una fonte (catalogo, pagina ufficiale, scelta dell'utente); un pattern senza fonte `ok` esce con una `Ruling:`. Costo: `**/middleware.*` e `**/proxy.*` sono percorsi esatti, quindi vincono contro la cartella di `backend`, `frontend` e `infra` (S7, S9, S47, S57); vincono anche contro la cartella di `ai` e di `database` (S71); accendono anche un `middleware.ts` che fa solo log, un `proxy.ts` che non è di Next.js (S46), un `middleware.test.ts`, un `middleware.config.json` (S59) e un `middleware.d.ts` (S66): quei lavori vanno in L2. Con `keep_paths` lo fanno anche quando un altro profilo riconosce il file per contenuto (S61-S64, decisione 4). Le cartelle `auth/` e `security/` vincono dentro le cartelle degli altri profili: una migrazione sotto `migrations/auth/` va a `security` con `database` attivo e `final-database` che parte lo stesso (S68), i gruppi di sicurezza di Terraform sotto `infra/security/` vanno a `security` (S69), un pacchetto di un monorepo che si chiama `auth` va tutto a `security`, `package.json` compreso (S70).
3. **`[detect] exclude = ["supabase/"]`** (mia scelta, dalla scelta dell'utente del progetto di B, sezione 12: le edge function sono di `database`). Senza, `supabase/functions/auth/` e `supabase/rls/` andrebbero a `security` (S11, S12, S43 con l'esclusione restano a `database`). L'esclusione vale anche per il rilevamento per contenuto. Vale **solo alla radice**, come l'`exclude` di `backend` e `frontend` e come `supabase/**` di `database` (decisione 3 di B7): una cartella `supabase/` annidata in un monorepo non è di `database`, e una sua edge function sotto `auth/` va a `security` (S56). Costo: una edge function di login alla radice riceve le regole di `database` (segreti, `verify_jwt`), non quelle di `security`; in un monorepo le riceve `security`. La pagina lo porta in «Da decidere tu».
4. **Rilevamento per contenuto e `keep_paths`** (scelte dell'utente del 22/11).
   - **Marcatori: librerie di password e di token.** Lista candidata, ogni voce da confermare nel Task 4 Step 0 (punto (a)): `bcrypt` e `bcryptjs` (`from 'bcrypt'`, `from "bcrypt"`, `require('bcrypt')`, `from 'bcryptjs'`, `require('bcryptjs')`), `argon2` per Node (`from 'argon2'`, `require('argon2')`), `jsonwebtoken` (`from 'jsonwebtoken'`, `require('jsonwebtoken')`), `jose` (`from 'jose'`), `iron-session` (`from 'iron-session'`), e per Python `import bcrypt`, `from argon2 import`, `from passlib`, `import jwt` (PyJWT), `from jose import` (python-jose), ognuno nelle due forme di virgolette dove serve (decisione 3 di B5). **Non** sono marcatori: le librerie di login complete (NextAuth/Auth.js, better-auth, Lucia, Clerk), i client dei servizi (`@supabase/ssr`, `@supabase/supabase-js`, Firebase), `crypto`/`hashlib`/`hmac` della libreria standard (troppo larghi).    - **Un file trovato per contenuto da un altro profilo accende anche `security`, se è in un percorso di `security`** (scelta dell'utente del 22/11 per le cartelle; mia scelta, nella stessa direzione, per i file per nome: un `middleware.ts` o un `proxy.ts` che importa Express o Hono è il caso più comune di middleware). La pagina lo porta in «Da decidere tu», anche per la parte «mia scelta» sui file per nome.
