## Review Focus

1. **Chiave che esce.** Un errore di rete o HTTP con la chiave in una variabile: né le righe, né la cache, né il testo di `FetchError`, né `repr` dell'eccezione, né la sua catena (`__context__`) contengono la chiave; per Gemini l'URL della richiesta non ha `key=`. Test: Task 2 `test_key_never_in_errors_lines_or_cache`, `test_gemini_key_in_header_not_url`.
2. **Rete lenta, assente o strana.** Tempo scaduto, 401, 429, 500, redirect, host diverso, HTML al posto del JSON, corpo oltre 8 MiB, JSON con la forma sbagliata, scadenza complessiva superata: ognuno dà una riga e `start` crea il lavoro con codice 0. Test: Task 2 `test_fetch_errors_are_fetch_errors`, `test_redirect_refused`, `test_other_host_refused`, `test_body_over_cap_stops`, `test_deadline_stops_between_chunks_and_pages`; Task 1 `test_parse_wrong_shape_raises`; Task 3 `test_check_never_raises`, `test_deadline_skips_remaining_providers`; Task 4 `test_start_succeeds_when_check_fails`.
3. **Falsi allarmi.** Un letterale che non è un modello (`"claude"`, `"gemini-cli"`, un percorso), un alias senza data, un ID di Vertex con `@`, un `*-latest`, un'anteprima più nuova di uno stabile, `flash-tts` contro `flash`, un modello con `created_at` all'epoca, `line` `null`: nessun avviso sbagliato. Test: Task 1 `test_literals_*`, `test_anthropic_newer_*`, `test_gemini_family_parse`, `test_unknown_prefix_only_for_versioned_names`, `test_alias_and_vertex_ids_not_flagged`.
4. **Elenchi a più pagine.** Anthropic con `has_more` e `last_id`, Gemini con `nextPageToken`, il tetto di 10 pagine. Test: Task 2 `test_anthropic_pages_followed`, `test_gemini_pages_followed`, `test_page_cap`.
5. **Configurazione, file e chiavi del progetto.** `[models] files` con un percorso assente su `origin`, uno con `..`, `*`, un a capo o assoluto, un file binario o troppo grande, la cache illeggibile, nessuna chiave o solo alcune, due fornitori con uno che fallisce, il componente spento. Test: Task 3 `test_missing_file_line`, `test_bad_paths_dropped_with_warning`, `test_binary_or_large_file_line`, `test_corrupt_cache_refetched`, `test_no_key_at_all_one_line_no_network`, `test_some_keys_missing_lines`, `test_one_provider_fails_other_reports`, `test_component_off_no_network`.
