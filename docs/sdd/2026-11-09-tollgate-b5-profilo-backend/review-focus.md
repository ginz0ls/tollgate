## Review Focus

1. **Un profilo che accende file sbagliati.** Un file sotto `supabase/functions/` (anche in `handlers/` o con `Deno.serve(`), uno sotto `.github/tollgate/` o nella cartella della proposta, un `src/services/api.ts`, un `src/api/client.ts`, un test con `from fastapi import`, un documento `server/README.md`: nessuno accende `backend`. Test: Task 1 `test_exclude_skips_paths_and_detect`, `test_exclude_only_for_its_fragment`; Task 3 `test_fragment_matches_decisions`, `test_fragment_leaves_out_services_and_supabase`; i test di B4 sui documenti e sui prefissi esclusi restano verdi.
2. **Il verticale sbagliato vince.** `api/vercel.json` e `server/Dockerfile` vanno a `infra`; `server/ai/x.py` va ad `ai`; un task su `wrangler.jsonc` e `src/index.ts` va al generico con `split_candidate`. Test: Task 6 `test_backend_and_infra_task_goes_generic`, `test_infra_file_inside_backend_folder_routes_to_infra`.
3. **Una scrittura remota senza veto, o una locale che blocca senza motivo.** `wrangler kv key put K V` (senza opzioni), `npx wrangler r2 object put b/k --file x`, `wrangler d1 execute DB --remote --command "…"`, `wrangler d1 migrations apply DB --preview`, `wrangler kv namespace delete` sono effetti; `wrangler kv key put K V --local`, `wrangler d1 execute DB --command "…"`, `wrangler d1 migrations create DB x`, `wrangler kv key get K` non lo sono. Test: Task 2 `test_wrangler_data_writes_are_effects`, `test_wrangler_local_writes_pass`, `test_wrangler_data_reads_pass`, `test_flag_effects_behind_launchers`, `test_text_effect_flag_entries`.
4. **Regole che nessuno può soddisfare o giudicare.** Ogni `[blocca]` di `rules-backend` si giudica sul diff o sul report; una regola su un endpoint dice come il revisore riconosce un endpoint nel diff; un `major` su una `R-BACKEND` non `[blocca]` non ferma; in un lavoro senza passo una `[blocca]` si soddisfa con diff e report. Test: Task 3 `test_blocking_rules_judged_on_diff_or_report`, `test_blocca_lines_have_text`, `test_endpoint_rules_say_how_to_recognize_an_endpoint`; Task 6 `test_backend_profile_non_blocking_rule_approves`, `test_backend_blocking_rule_without_step`.
5. **Un'evidenza con dati dell'utente o testo di terzi; un comando di servizio nella prova.** Nella prova il modello non può lanciare `wrangler`, `supabase`, `deno`, `node`, `npx`; le evidenze passano da `togli-pagine` (anche per i `Bash` che leggono `tool-results/`) e dal controllo dei valori sensibili. Test: Task 7 `test_flow_disallows_service_clis_backend`, `test_togli_pagine_bash_reading_saved_copy`, `test_real_flow_case_backend_project_has_no_credentials`; `test_committed_evidence_has_no_long_web_results` resta verde dopo il Task 8.
