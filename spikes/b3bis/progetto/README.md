# Progetto della prova vera di B3-bis

Progetto minimo che `spikes/b3bis/models-prova.sh prepara` copia in `$B3BIS_DIR/repo`.
Dichiara in `tollgate.toml` il solo file `ai/models.py`, che `tollgate models check`
confronta con gli elenchi dei fornitori. Il file nel repo contiene segnaposto: i modelli
veri li scrive chi esegue la prova, sulle pagine ufficiali, il giorno stesso.
